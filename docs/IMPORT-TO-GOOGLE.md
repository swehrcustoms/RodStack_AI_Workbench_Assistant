# Import RodStack navigation docs into Google

## Google Spreadsheet

1. Open [Google Sheets](https://sheets.google.com) → **Blank spreadsheet** (or your RodStack users sheet).
2. **File → Import → Upload** → choose `RodStack-Navigation-Links.csv` from this folder.
3. Import location: **Replace current sheet** or **Insert new sheet** (recommended name: `Navigation Links`).
4. Select row 1 → **Data → Create a filter** for easy sorting by Category.
5. Optional: select Production URL column → **Insert → Link** is automatic if URLs are plain text.

To add to your existing admin sheet (`1WRA19FBOlJ5idoQ9lVJL6miQJy2Sc5Uxvq0UuvfWt_A`):

- Open that spreadsheet → **+** tab → import CSV into the new tab.

## Google Doc

**Option A — Upload HTML (best formatting)**

1. Open [Google Docs](https://docs.google.com) → **Blank document**.
2. **File → Open → Upload** → select `RodStack-Admin-Navigation-Guide.html`.
3. Google converts it to an editable Doc with headings and tables.

**Option B — Copy from browser**

1. Double-click `RodStack-Admin-Navigation-Guide.html` to open in your browser.
2. Select all (Cmd+A) → Copy → paste into a new Google Doc.
