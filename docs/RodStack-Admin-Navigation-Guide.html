4. Production Bench modules (same page)

Open #view=bench, then scroll or use the sidebar:

  • Blank Architecture (manufacturer, model, material, length, action, power)
  • Spine Finder — guided flex profile (replaces legacy spine slider)
  • Handle Assembly
  • Guide Spacing matrix
  • QC / Bench Validation — temp & humidity (shared with Cure Tracker)
  • Cure Tracker — epoxy coats, recoat countdown
  • Wrap & Finish — thread colors, customer, order notes
  • Build Photo Log — upload, captions, export zip
  • Bench Mode — toggle in top nav for large mobile layout + Quick Log

8. Troubleshooting

  • #admin loads the admin app; #view=… loads the workshop app. Do not mix them in one URL.
  • If a hash link opens the wrong screen, clear rodstack.app.v2 in DevTools → Application → Local Storage, or use a private window.
  • Supabase cloud sync: set VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY; run supabase/schema.sql in your project.
